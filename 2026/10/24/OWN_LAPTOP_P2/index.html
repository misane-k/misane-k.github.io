【未润色】设计一台自己的电脑（第二部分）：外设

还没完成的上一部分讲述了豆小谷F11的逆向，我可以专注于主板的设计，之后有必要再重新设计外壳。
接下来是外设芯片的选择。

软件的边界

我一直很疑惑，当我按下电源键时，电脑是怎么开关机的。
关机时短按电源键可以开机，开机时短按可以关机/休眠，长按可以强制关机。所以是软件还是硬件控制的呢？
你也许知道，在很多平台上，往特定内存地址写一个魔数，就能关机/重启，所以软件是参与控制的。
你也许还知道，当你往某些地址写值时，IO引脚的高低电平会发生变化，这样可以控制外设的通断电。
但是当软件死机了呢，怎么实现长按关机的呢？以及没开机的时候呢？

所以需要EC（嵌入式控制器），它是一颗独立的芯片，上电后会一直运行。
由它检测按键电平，控制三极管的开关，上电的顺序等。以及通过协议（例如GPIO, I2C）将事件上报给主控
这样可以实现开机、强制关机，并由主控解释电源键的行为。
EC可以是专用芯片，也可以是用MCU。我才发现，很多专用芯片是用带有固件的MCU伪装的。
例如TypeC转DP视频输出模块，使用的是CH543D，这是一个8位单片机。
但是刷入固件后，就可以当协商芯片使用。

选择核心板

我之前看到过一个视频，高中生自己DIY的开源笔电。
虽然我当时看不懂，但是我记下来一些关键词：CM3588核心板、6层板、eDP线序。
如今我设计电脑，也选择了购买核心板、自己设计底板的方案。
我还有机会实现一些他没能实现的功能，例如显示屏上的摄像头、耳机插入检测、DP Alt输出。

我不喜欢树莓派的btb连接器，连接器不好找也贵。我还想同一套底板兼容riscv/arm核心板。
于是我找到了K3-CoM260。K3是2026年新出的riscv芯片，性能我觉得还行。
核心板使用DDR4 SO-DIMM引出，而且宣称与jetson orin nano兼容。我挺满意的。

实现

原有主板上有很多钻孔，我需要测量出位置在我的PCB上也打过孔，这样才能和外壳匹配。
测量完主板就没用了，可以卖掉了（不是）
上一篇文章中，我通过逆向得知了F11的外设，如带有保护板的锂电池、26pin键盘、I2C触摸板、eDP显示屏。
梳理一下我的需求：

  • TypeC 快充输入/输出 x1
  • TypeA USB3 Host x3 + TypeC Device x1
  • 千兆以太网 + 可选的PoE输入
  • eDP屏幕 x1，DP输出 x1
  • WiFi + 蓝牙
  • 两个 M.2 硬盘
  • 扬声器 x2 + 麦克风 x2 + 耳机
  • 键盘 + 触摸板
  • 显示电池/充放电 的 功率/温度，以及电池容量

再看看核心板引出了什么接口：

  • TypeC DRP x1
  • PCIe + USB3 Mux
  • DP x1 + MIPI DSI x1（jetson没有）
  • USB2 x3
  • 千兆以太网MDI x1
  • MMC x1, I2S x2, UART, I2C, SPI, PWM

大部分都是可以满足的：

  • 快充输入/输出，可以选择升降压一体的芯片，例如BQ25792 + TPS25751，无需管理
  • PoE，可以通过将网络变压器中心抽头引出，连到PoE协商芯片 + 隔离DCDC即可
  • 扬声器 + 麦克风 + 耳机，用I2S的音频管理芯片，支持上报耳机插入检测事件，由主控选择输出
  • 键盘 + 触摸板由RP2040管理，上报为USB输入设备
  • 电池容量可以用电量计得到，通过I2C上报
  • DP Alt用CH543D + CH9445F 编写固件实现

有些有多种实现方式：

  • 可以选择用PCIe扩展四个USB3，或者USB3扩展坞
  • 千兆以太网可以用MDI，也可以用USB3转网口
  • WiFi + 蓝牙，可选PCIe或者SDIO的无线模块
  • M.2，核心模提供的PCIe足够，也可以考虑加PCIe Switch

但是也有不好实现的内容：
K3虽然支持输出两路DP，但是核心板只引出一路，而且K3不支持DP MST。
jetson orin nano 只支持一路DP输出，没有其他显示输出。
笔记本不支持投屏的话，做汇报都很困难。
我打算先预留排线，之后用FPGA（例如XC7A35T-FGG484）实现简易外置显卡，

简化电源树

RP2040管理1-4上电时序，以及键盘、触摸板、电量计上报

目前还在打板验证，有进展再更新
