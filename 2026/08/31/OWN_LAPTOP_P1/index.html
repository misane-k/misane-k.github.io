设计一台自己的笔记本（第一部分）：逆向

我一直想设计一款自己的电脑，但是从头设计很难。
一方面我不知道用什么元件好，例如触摸板、电池的型号，以太网连接器的高度、是否全包裹、是否沉版等。
另一方面需要设计外壳，和键盘、屏幕、主板等装配起来，我之前设计的扩展坞外壳总是松松垮垮的，我没有信心。
于是我决定拆一个笔记本，参考成熟的商业设计。

需求

  • 我希望参考笔记本尽可能便宜，意外损坏时替换不心疼。
  • 我希望它内部有较多空间，结构清晰，异形板尽可能少，方便我学习和替换。
  • 我希望它是量产的产品，这样在市场上有大量存货，几年后我依然能找到替换件。

拆机

首先，我拆开了我的游戏本。我发现游戏本内部满满当当，甚至还有金属隔断起到支撑和保护作用，需要从上到下依次取下，光拆一次就很费劲。
游戏本引出了大量接口，例如SATA, 雷电, 多个HDMI。这些并非必须，目前还会增加我理解和实现的难度。
而且游戏本太贵了，一旦烧坏器件，我很难再买第二个。

其次，我拆过几个平板，平板便携性很出色、还有我喜欢的触摸屏。
不过平板内部寸土寸金，主板和小板都是异形板，MIPI屏幕、基带没有任何资料。
最关键的是，大多数平板只引出一个TypeC接口，这样同时接键盘鼠标和充电都费劲。

然后，我搜了一些diy套件，但是真的太贵了。我不理解一个亚克力/金属外壳，怎么能买到500+的。

一年前，我在捡垃圾的时候，买到了一个叫 豆小谷F11 的笔记本（并非广告）。
性能不强，用的甚至是赛扬处理器 + 被动散热。我玩了一段时间就丢角落吃灰了。
某一天，我把它拆开，发现它内部很空旷，甚至连一半的空间都没用上。
这在平时是劣势，我会认为是偷工减料，但是此刻成为巨大的优势。
作为一个廉价笔记本，拥有必要的接口：一个充电口，3个USB TypeA，一个以太网，一个3.5mm耳机孔，底部可替换nvme硬盘，带有屏幕、键盘、触摸板。
我只需要实现必要的部分即可，于是我着手测量外设的线序，以便我自己设计主板驱动外设，最终集成为一个完整的笔记本。

测量过程

在系统中，可以看到屏幕的型号，在网上搜索发现是eDP 30pin，不过FPC的线序明显与标准线序不同，这一条线同时包含了屏幕和摄像头。
在PCB上，差分对、大面积铺铜的特征很明显，由此可以初步确定哪些是高速信号，哪些是电源。
我在电脑运行时，用万用表测电压，得到全部引脚的电压，例如屏幕的8V就是背光电压，还测量了0V与GND的通断，来区分控制信号和电源地。
我调节屏幕的亮度，发现有一个引脚的电压值在降低（背光pwm）。
不过我还是没法确定差分通道具体是怎么排列的，最后我拆开了屏幕，对比定制线两端的颜色，得到了线序。

剩下的比较简单，某些连接器，例如触摸板旁边标注了丝印，INT/SCL/SDA均有写，用万用表测通断即可确认部分线序。
键盘3.3V/0V即可区分行和列，我按下键盘一个键（win），发现有一个引脚从3.3V到0V，确实是无源的扫描键盘。
不过我都测完了线序，才发现 豆小谷F11 产品非常乱，有14/15.6寸屏幕、12V/19V输入、左侧1/2个TypeA的笔记本，底部标注的全是 豆小谷F11。
我在某鱼，买了三个外观相似的，但是内部完全不同，我以第一个拆机的为准，以下是外设线序。
在下一篇文章，我会如何设计自己的主板，来驱动这些外设。

线序

屏幕 30pin-0.5mm

pin pin_1 pin_2 pin_3 pin_4 pin_5 pin_6
0> g 1p 1n g 0p 0n
6> g an ap g x x
12> g x x nc g g
18> 8 8 g 3.3 3.3 hpd
24> pwm blen g dp dm 5

键盘 28pin 1mm

pin pin_1 pin_2 pin_3 pin_4 pin_5
0> 3.3 3.3 0(win) 3.3 3.3
5> 3.3 0 0 3.3 3.3
10> 0 3.3 0 0 0
15> 0 0 0 0 0
20> 0 0 0 0 3.3(power)
25> g nc nc

触摸板 10pin 0.5mm

pin pin_1 pin_2 pin_3 pin_4 pin_5
0> 0 0 5 5 tp(0)
5> int scl sda g 3.3

触摸板（未贴） 6pin 1mm

pin pin_1 pin_2 pin_3 pin_4 pin_5
0> 3.3 scl(1.8) sda(1.8) int(0.4) tp(0)
5> g

2S电池 10pin 1.25mm 超薄

pin pin_1 pin_2 pin_3 pin_4 pin_5
0> g g g g ntc(10k)
5> nc nc v v v

麦克风/扬声器 5pin 0.8mm

type pin_1 pin_2 pin_3 pin_4 pin_5
mic rp rn nc lp ln
spk lp ln nc rn rp
